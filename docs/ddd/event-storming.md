# Event Storming

O **Event Storming** é um método colaborativo de modelagem rápida e visual para explorar domínios de negócio complexos, identificar **Eventos de Domínio**, **Comandos**, **Políticas (Regras de Negócio)**, **Agregados** e os limites de contexto (**Bounded Contexts**).

Para atender integralmente aos requisitos da Fase 1 do Tech Challenge, o domínio foi modelado em boards colaborativos no Miro e documentado em três fluxos principais:
