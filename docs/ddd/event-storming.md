
# Event Storming

Nesta página, documentamos o **Event Storming**, um workshop colaborativo focado na exploração de fluxos de domínio de negócios de forma visual. O objetivo é mapear o que acontece no sistema (Eventos de Domínio), os comandos que os geram, as reações em cadeia e os agregados relacionados ao **Sistema Integrado de Atendimento e Execução de Serviços**.
