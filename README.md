# 🛠️ 18SOAT - Oficina Mecânica (Fase 1)

Projeto para o desenvolvimento da primeira versão (MVP) do back-end para gestão de oficinas mecânicas, aplicando Domain-Driven Design (DDD), arquitetura em camadas e práticas de Qualidade de Software.

---

### 📋 Escopo da Entrega

- **Domain-Driven Design (DDD):** Linguagem Ubíqua, Event Storming e Diagramas de Domínio e Contexto.
- **Desenvolvimento Back-end:** Monolito modular (Arquitetura em Camadas) implementando a gestão de Ordens de Serviço (OS), Clientes, Veículos e Peças com controle de estoque.
- **Segurança & Validações:** Autenticação via JWT para APIs administrativas e validação de documentos sensíveis (CPF/CNPJ e Placas).
- **Qualidade & DevOps:** Cobertura de testes unitários/integração (mínimo 80% nos domínios críticos), relatório de vulnerabilidades (SAST), Dockerfile e docker-compose.
